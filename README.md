# Robustness of Convolutional Neural Networks to Common Image Corruptions

CSCI 494 — Deep Learning, Fall 2026

Project scaffold for the Robustness to Noise project.

Core experiment:
CIFAR-10 -> Clean CNN -> Gaussian noise / Gaussian blur / brightness (severity 1-5)
-> Robust CNN with corruption-aware augmentation -> controlled comparison and analysis.

This repository scaffold contains the planned folders and placeholder files.
